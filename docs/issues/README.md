# Issues

One file per issue. The **list, grouped by difficulty** (🟢 good first, 🟡 medium, 🔴 hard), is in the project **[README](../../README.md#open-issues)**.

- How to pick and work on an issue: [CONTRIBUTING.md](../../CONTRIBUTING.md).
- How to write a new one: [CONTRIBUTING.md, section 6](../../CONTRIBUTING.md#6-writing-a-new-issue). Then add a row to the README table.
- When the project moves to GitHub, these files can become GitHub issues. Keep the number in the title (`#012 …`) so pull requests can refer to it.
